# 💀 OMEGA_SPECTRE_GODFALL

## 📖 نظرة عامة

**OMEGA_SPECTRE_GODFALL** هو أقوى إسكربت في العالم، يحتوي على أكثر من 160 ملفاً و 19 محركاً إلهياً للتحكم الكامل في كل شيء.

## 🛠️ التثبيت

### المتطلبات
- Python 3.11+
- MongoDB 5+
- Redis 7+

### الخطوات
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-username/omega-spectre-godfall.git
cd omega-spectre-godfall

# 2. إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # أو venv\Scripts\activate على Windows

# 3. تثبيت الاعتماديات
pip install -r requirements.txt

# 4. إعداد متغيرات البيئة
cp .env.example .env
# عدل الملف

# 5. تشغيل الإسكربت
python main_godfall.py
